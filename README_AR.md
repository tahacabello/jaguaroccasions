# 🎓 جاغوار للمناسبات (Jaguar Occasions)

هذا هو الإصدار النهائي والمحدث من مشروع منصة التجارة الإلكترونية "جاغوار للمناسبات".
المنصة مخصصة لبيع وإيجار مستلزمات التخرج الفاخرة (كابات، شالات، قبعات، بروشات).

---

## 🌟 الميزات التي تمت إضافتها في هذا التحديث:
1. **تجربة المستخدم والواجهة:**
   - **الوضع الليلي والنهاري (Dark/Light Mode):** نظام مخصص بالكامل مع ألوان زجاجية فاخرة تتغير بسلاسة.
   - **المفضلة (Wishlist):** يمكنك النقر على أيقونة "القلب" لحفظ المنتجات، ومراجعتها في صفحة `/wishlist` المخصصة.
   - **حركات وتأثيرات بصرية (Animations):** ظهور سلس (Fade in) وتأثيرات تركيز أنيقة في جميع صفحات الموقع.

2. **التسوق والطلب:**
   - **نظام الكوبونات (Coupons):** تم دمج نظام خصومات في صفحة الدفع. (مثال: كود `JAGUAR20` يعطي خصم 20%، وكود `MINUS50` يخصم 50 دينار).
   - **البحث والفلترة:** في صفحة `/products` يمكنك الآن البحث باسم المنتج، فلترة الحالة (متوفر/محجوز)، وترتيب المنتجات حسب السعر.

3. **التقييمات والآراء (Reviews):**
   - صفحة تفاصيل المنتج تدعم الآن نظام تقييم 5 نجوم يمكن للزبائن كتابة آرائهم فيه.

4. **لوحة الإدارة (Admin Dashboard):**
   - إضافة رسم بياني شريطي (Bar Chart) يوضح مبيعات المنتجات.
   - إمكانية تصدير بيانات الطلبات والمنتجات كملف إكسيل (`CSV`).

---

## ⚙️ التقنيات المستخدمة:
- **Next.js 14:** إطار العمل الأساسي.
- **Tailwind CSS:** لتصميم الواجهات الفاخرة.
- **React Context:** لإدارة حالة السلة (Cart) والمفضلة (Wishlist) والوضع الليلي (Theme).

---

## 🚀 كيفية تشغيل المشروع على جهازك:

بما أننا واجهنا صعوبة في تثبيت `Node.js` سابقاً، يرجى التأكد من أنك قمت بتثبيت `Node.js` على جهازك بنجاح من الموقع الرسمي (https://nodejs.org).

بعد التأكد من وجود Node.js، اتبع الخطوات التالية:

1. قم بفك ضغط هذا المجلد في أي مكان على جهازك.
2. افتح المجلد بواسطة برنامج **Visual Studio Code** (أو أي محرر أكواد).
3. افتح موجه الأوامر المدمج (Terminal) داخل المحرر.
4. قم بتشغيل الأمر التالي لتحميل الحزم الأساسية:
   ```bash
   npm install
   ```
5. بعد انتهاء التحميل، قم بتشغيل الأمر التالي لبدء الموقع:
   ```bash
   npm run dev
   ```
6. سيظهر لك رابط في الـ Terminal (عادةً ما يكون `http://localhost:3000`). اضغط عليه لفتح الموقع في متصفحك!
